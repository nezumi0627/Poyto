# MCP environment

| Variable | Default | Description |
| --- | --- | --- |
| `POYTO_MCP_TRANSPORT` | `stdio` | MCP transport |
| `POYTO_MCP_HOST` | `127.0.0.1` | network listener address |
| `POYTO_MCP_PORT` | `8765` | network listener port |
| `POYTO_MCP_READ_ONLY` | `false` | omit mutation tools |

Poyto's normal authentication/session variables remain unchanged, including `POYTO_SESSION_FILE`.
