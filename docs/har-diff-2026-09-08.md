# HAR findings — 2026-09-08

The supplied captures established the current Poyto baseline.

## Authentication

Observed flow: Apple `id_token` / access token / nonce → Supabase auth at `auth.poyp.app` → bearer access token → `api.poyp.app`.

## First captures

Confirmed profile, balances, portfolio, missions, login streak, notifications, referral, market listing/detail, positions, rankings, global chat, home/discovery APIs, provider rewards, push-token registration, ad reward claim, and event submission.

## Later capture additions

A later HAR added request shapes that were previously unknown:

- `POST /api/trades/sell`
- comment create/reply/edit/delete/like
- follow and unfollow
- public user profile/follower/following/history endpoints
- market activity and market chart endpoints
- asset price endpoint
- account balance transaction history
- blocked-user list

These additions replaced earlier placeholders with dedicated methods backed by observed requests.

## Still intentionally not inferred

Operations not seen in the supplied traffic remain undocumented rather than guessed. When a new HAR contains one of those actions, add its exact request shape plus a mock test.
